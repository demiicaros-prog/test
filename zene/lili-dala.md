# Lili dala

Vidám gyerekdal · C-dúr · 120 BPM · 4/4
Felépítés: előjáték – 1. vsz. – refrén – 2. vsz. – refrén – 3. vsz. – refrén – 4. vsz. – refrén ×2 – lezárás

## 1. versszak – mászik
```
C              G
Fel a fára, fel a dombra,
Am             F
mászik Lili, fel a lombba,
C              G
le se néz, csak egyre feljebb,
F     G        C
onnan a világ sokkal szebb!
```

## Refrén
```
F              G
Lili, Lili, négy éves már,
C              Am
fut és szalad, mint a madár!
F              G
Okos kislány, mindent tud,
F              C
Lili, Lili, hipp-hopp-hupp!
```

## 2. versszak – biciklizik
```
C              G
Két kis kerék, egy kis csengő,
Am             F
Lili teker, fúj a szellő,
C              G
kling-kling-kling, jön Lili már,
F     G        C
félre, félre, aki ott jár!
```

## 3. versszak – túrázik
```
C              G
Hátizsákkal útra kel,
Am             F
dombra fel és völgybe le,
C              G
mókust lát és őzikét,
F     G        C
erdő, mező, de szép, de szép!
```

## 4. versszak – olvas
```
C              G
Este, ha már lemegy a nap,
Am             F
Lili könyvet a kezébe kap,
C              G
mesék, állatok, csillagok,
F     G        C
Lili tudja: okos vagyok!
```

*(Refrén kétszer, a végén mindenki tapsol!)*
